# JavaScript Reserved Keywords

Here is the complete list of reserved keywords in JavaScript, categorized by their general purpose. You cannot use these words as variables, labels, or function names because they are built into the language.

### Variable & Data Declarations
- `var`
- `let`
- `const`
- `enum`

### Control Flow
- `if`
- `else`
- `switch`
- `case`
- `default`
- `break`
- `continue`

### Loops
- `for`
- `while`
- `do`

### Functions & Classes
- `function`
- `return`
- `class`
- `extends`
- `super`
- `yield`

### Error Handling
- `try`
- `catch`
- `finally`
- `throw`

### Objects, Context, & Types
- `this`
- `new`
- `delete`
- `typeof`
- `instanceof`
- `in`
- `null`

### Modules
- `import`
- `export`

### Asynchronous Programming
- `await` *(Inside async functions)*

### Other Utilities
- `debugger`
- `void`
- `with` *(Deprecated in strict mode)*

---

### Future Reserved Keywords (in Strict Mode)
These words are reserved for potential future features and cannot be used in strict mode (`"use strict";`):
- `implements`
- `interface`
- `package`
- `private`
- `protected`
- `public`
