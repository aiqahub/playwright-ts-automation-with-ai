# Visual Studio Code Shortcuts (Windows)

Here are the most essential shortcuts for navigating and managing views in VS Code on Windows.

## 💻 Terminal View Shortcuts
* **Open/Toggle Terminal:** ``Ctrl + ` `` (the backtick key, usually above Tab)
* **Open a New Terminal:** ``Ctrl + Shift + ` ``
* **Split Terminal:** `Ctrl + Shift + 5`
* **Focus Terminal (from editor):** ``Ctrl + ` ``
* **Focus Editor (from terminal):** `Ctrl + 1` (focuses the first editor group)
* **Scroll Terminal Up/Down:** `Ctrl + Up Arrow` / `Ctrl + Down Arrow`
* **Clear Terminal:** `Ctrl + K` (or type `cls` in PowerShell/CMD)

## 📁 Explorer View Shortcuts
* **Open/Focus Explorer:** `Ctrl + Shift + E`
* **Toggle Sidebar (Hide/Show):** `Ctrl + B`
* **New File (when Explorer is focused):** `Ctrl + N`
* **Rename File/Folder (when selected):** `F2`
* **Delete File (when selected):** `Delete`

## 🔎 Other Useful View Shortcuts
* **Search View:** `Ctrl + Shift + F`
* **Source Control (Git):** `Ctrl + Shift + G`
* **Extensions:** `Ctrl + Shift + X`
* **Command Palette:** `Ctrl + Shift + P` (Access to all commands and features)

# VS Code Keyboard Shortcuts — macOS

> Default keybindings for Visual Studio Code on macOS.


---

## General

| Shortcut | Action |
|----------|--------|
| `Cmd + Shift + P` | Command Palette |
| `Cmd + P` | Quick Open, Go to File |
| `Cmd + Shift + N` | New Window |
| `Cmd + W` | Close Window |
| `Cmd + ,` | User Settings |
| `Cmd + K Cmd + S` | Keyboard Shortcuts |

---

## Basic Editing

| Shortcut | Action |
|----------|--------|
| `Cmd + X` | Cut Line (empty selection) |
| `Cmd + C` | Copy Line (empty selection) |
| `Cmd + V` | Paste |
| `Cmd + Shift + K` | Delete Line |
| `Cmd + Enter` | Insert Line Below |
| `Cmd + Shift + Enter` | Insert Line Above |
| `Cmd + Shift + \` | Jump to Matching Bracket |
| `Cmd + ]` | Indent Line |
| `Cmd + [` | Outdent Line |
| `Cmd + /` | Toggle Line Comment |
| `Cmd + Shift + A` | Toggle Block Comment |
| `Option + Up/Down` | Move Line Up/Down |
| `Shift + Option + Up/Down` | Copy Line Up/Down |
| `Cmd + Shift + L` | Select All Occurrences of Current Selection |
| `Cmd + D` | Add Selection to Next Find Match |
| `Cmd + K Cmd + D` | Move Last Selection to Next Find Match |

---

## Navigation

| Shortcut | Action |
|----------|--------|
| `Ctrl + G` | Go to Line |
| `Cmd + T` | Show All Symbols |
| `Cmd + Shift + O` | Go to Symbol in File |
| `Cmd + Shift + M` | Show Problems Panel |
| `F8` | Go to Next Error or Warning |
| `Shift + F8` | Go to Previous Error or Warning |
| `Ctrl + Shift + Tab` | Navigate Editor Group History |
| `Ctrl + -` | Navigate Back |
| `Ctrl + Shift + -` | Navigate Forward |

---

## Search and Replace

| Shortcut | Action |
|----------|--------|
| `Cmd + F` | Find |
| `Cmd + H` | Replace |
| `Cmd + Shift + F` | Find in Files |
| `Cmd + Shift + H` | Replace in Files |

---

## Multi-Cursor and Selection

| Shortcut | Action |
|----------|--------|
| `Option + Click` | Insert Cursor |
| `Cmd + Option + Up/Down` | Add Cursor Above/Below |
| `Cmd + U` | Undo Last Cursor Operation |
| `Shift + Option + I` | Insert Cursor at End of Each Line Selected |
| `Cmd + Shift + L` | Select All Occurrences of Current Selection |
| `Cmd + F2` | Select All Occurrences of Current Word |
| `Cmd + I` | Select Current Line |

---

## Editor Management

| Shortcut | Action |
|----------|--------|
| `Cmd + W` | Close Editor |
| `Cmd + K W` | Close All Editors |
| `Cmd + \` | Split Editor |
| `Cmd + 1/2/3` | Focus Into 1st/2nd/3rd Editor Group |
| `Cmd + K Cmd + Left/Right` | Move Editor Left/Right |

---

## Display

| Shortcut | Action |
|----------|--------|
| `Ctrl + Cmd + F` | Toggle Full Screen |
| `Cmd + =` | Zoom In |
| `Cmd + -` | Zoom Out |
| `Cmd + B` | Toggle Sidebar Visibility |
| `Cmd + Shift + E` | Show Explorer |
| `Cmd + Shift + F` | Show Search |
| `Cmd + Shift + G` | Show Source Control |
| `Cmd + Shift + D` | Show Run and Debug |
| `Cmd + Shift + X` | Show Extensions |
| `Ctrl + Shift + `` | Show Integrated Terminal |
| `Cmd + Shift + V` | Open Markdown Preview |
| `Cmd + K V` | Open Markdown Preview to the Side |

---

## Debug

| Shortcut | Action |
|----------|--------|
| `F5` | Start/Continue |
| `F9` | Toggle Breakpoint |
| `F10` | Step Over |
| `F11` | Step Into |
| `Shift + F11` | Step Out |
| `Shift + F5` | Stop |
| `Cmd + K Cmd + I` | Show Hover |

---

## Integrated Terminal

| Shortcut | Action |
|----------|--------|
| `` Ctrl + ` `` | Toggle Integrated Terminal |
| `` Ctrl + Shift + ` `` | Create New Terminal |
| `Cmd + C` | Copy Selection (when terminal focused) |
| `Cmd + V` | Paste into Terminal |
| `Cmd + Up/Down` | Scroll Up/Down |
| `Shift + PgUp/PgDn` | Scroll Page Up/Down |

> **Tip:** Use `Cmd + K Cmd + S` to view and customize any shortcut.
