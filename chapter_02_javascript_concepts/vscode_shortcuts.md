# Visual Studio Code Shortcuts (Windows)

Here are the most essential shortcuts for navigating and managing views in VS Code on Windows.

## 💻 Terminal View Shortcuts
* **Open/Toggle Terminal:** ``Ctrl + ` `` (the backtick key, usually above Tab)
* **Open a New Terminal:** ``Ctrl + Shift + ` ``
* **Split Terminal:** `Ctrl + Shift + 5`
* **Focus Terminal (from editor):** ``Ctrl + ` ``
* **Focus Editor (from terminal):** `Ctrl + 1` (focuses the first editor group)
* **Scroll Terminal Up/Down:** `Ctrl + Up Arrow` / `Ctrl + Down Arrow`
* **Clear Terminal:** `Ctrl + K` (or type `cls` in PowerShell/CMD)

## 📁 Explorer View Shortcuts
* **Open/Focus Explorer:** `Ctrl + Shift + E`
* **Toggle Sidebar (Hide/Show):** `Ctrl + B`
* **New File (when Explorer is focused):** `Ctrl + N`
* **Rename File/Folder (when selected):** `F2`
* **Delete File (when selected):** `Delete`

## 🔎 Other Useful View Shortcuts
* **Search View:** `Ctrl + Shift + F`
* **Source Control (Git):** `Ctrl + Shift + G`
* **Extensions:** `Ctrl + Shift + X`
* **Command Palette:** `Ctrl + Shift + P` (Access to all commands and features)
