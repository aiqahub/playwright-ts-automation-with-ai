# Learn Playwright with JavaScript 🚀

Welcome to the **Learn Playwright** repository! This project serves as a comprehensive learning journey and practical guide for mastering automation testing. It starts with the core fundamentals of JavaScript and progresses into building advanced UI and API test automation frameworks using [Playwright](https://playwright.dev/).

---

## 📖 What's Inside?

This repository is structured into distinct learning phases to build your knowledge from the ground up:

### Phase 1: JavaScript Foundations
Before diving into automation, a strong understanding of JavaScript is required. The initial chapters contain practical exercises focusing on:
- How JavaScript executes under the hood (V8 Engine, Event Loop, Call Stack)
- Variables, Scope (`var`, `let`, `const`), and naming conventions
- Core JavaScript concepts, commands, and comments
- Handling asynchronous operations (Promises, Async/Await)

### Phase 2: Playwright Learning Exercises (Upcoming)
Interactive, hands-on exercises to learn the Playwright API:
- Browser and Browser Context management
- Robust Locators and interacting with dynamic web elements
- Built-in Assertions, Actions, and handling complex UI components (iframes, tabs, popups)
- Network interception and mocking

### Phase 3: Automation Frameworks (Upcoming)
Applying the learned concepts to build robust, scalable, and maintainable testing frameworks from scratch:
- **UI Automation Framework**: Automating complex, end-to-end user journeys on web applications using the Page Object Model (POM).
- **API Testing Framework**: Automating REST API endpoints, response validations, and data-driven testing.
- Integration with HTML reporters, trace viewers, and CI/CD pipelines.

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/aiqahub/playwright-ts-automation-with-ai.git
   ```
2. **Navigate into the project directory**:
   ```bash
   cd LEARNPLAYWRIGHT
   ```
3. **Execute JavaScript Exercises**:
   You can run the foundational JavaScript files using Node:
   ```bash
   node chapter_01_basics/03_JS_commands.js
   ```
*(Note: Instructions for installing Playwright and running tests will be added here once Phase 2 begins!)*
